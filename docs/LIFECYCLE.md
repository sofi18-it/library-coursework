# Чотиристанний життєвий цикл бронювання

```text
CREATED → CONFIRMED → READY_FOR_ISSUE → COMPLETED
```

- `CREATED` — бронювання зареєстровано, його поля можна виправити або видалити.
- `CONFIRMED` — бібліотека підтвердила бронювання.
- `READY_FOR_ISSUE` — примірник виділено для видачі. Перехід заборонено, якщо доступних примірників немає.
- `COMPLETED` — примірник видано; в одній транзакції створюється запис `Loan` і зменшується доступний фонд.

Service перевіряє, що запитаний стан є наступним у переліку. Перехід назад, повторний перехід і пропуск стану повертають HTTP 409. У разі повернення примірника `LoanService` записує дату повернення і збільшує доступну кількість.
