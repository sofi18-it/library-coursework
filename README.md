# Курсовий проєкт, варіант 4

Інформаційна система бронювання та видачі бібліотечних видань. Проєкт розділено на два незалежні Maven-модулі: `server` (Servlet API 4 / Tomcat 9, Service, DAO/JDBC, MySQL) та `client` (JavaFX, HTTP/JSON).

## Модель предметної області

- `Publication` — бібліографічні дані видання та кількість примірників.
- `Reader` — дані читача.
- `Booking` — бронювання видання читачем і його життєвий цикл: `CREATED → CONFIRMED → READY_FOR_ISSUE → COMPLETED`.
- `Loan` — фактична видача примірника за завершеним бронюванням.

Фактори інтегрального показника нормуються до 0–100:

- F1 — тривалість очікування: `min(днів очікування / 30 × 100, 100)`; у БД зберігається нормований бал `f1_wait_score`.
- F2 — попит на видання: `100 × активні бронювання / примірники у фонді`, обмежений 100.
- F3 — дефіцит доступних примірників: `100 × max(активні бронювання − доступні примірники, 0) / примірники у фонді`, обмежений 100.
- I = `0.40 × F1 + 0.35 × F2 + 0.25 × F3`.

Ці формалізації факторів зроблені для реалізації показників, названих в індивідуальному завданні; за наявності окремої формули викладача замініть їх у `BookingService` і пояснювальній записці.

## Запуск

1. Створити БД, виконавши `database.sql` у MySQL/phpMyAdmin.
2. Налаштувати `DB_URL`, `DB_USER`, `DB_PASSWORD` (за замовчуванням URL веде до локальної БД `library_coursework`).
3. Зібрати сервер: `cd server` → `mvn clean package`; розгорнути `target/library-server.war` у Tomcat 9.x.
4. Запустити JavaFX-клієнт: `cd client` → `mvn javafx:run`. Базова адреса сервера задається через `LIBRARY_API_URL` (за замовчуванням `http://localhost:8080/library-server/api`).

Докладні маршрути та формат CSV описані в `docs/API_AND_DATA.md`. Перший рядок CSV — заголовок: `isbn,title,author,publisher,publication_year,category,total_copies`.

Початкова пояснювальна записка підготовлена у `docs/Пояснювальна_записка_КПП_варіант_4.docx` та PDF-копії поруч. У документі зафіксовано поточний стан реалізації й відомі кроки, які залишилися для GitHub та навчального середовища.

## Стан перевірки

Обидва Maven-модулі зібрано успішно: `server` створює `library-server.war`, `client` компілюється. WAR розгорнуто у тимчасовому Tomcat 9; MySQL скрипт виконано, HTTP-відповіді та CRUD, дозволені/заборонені переходи, видачу і повернення примірника перевірено. JavaFX-клієнт запускається; реальні знімки каталогу та бронювань збережено в `docs/screenshots/`.

Перевірку виконано на тимчасових локальних MySQL і Tomcat. На цьому етапі не додані JUnit 5 тести. GitHub URL не надано, тому віддалений репозиторій і push ще не налаштовані. Деталі тестових сценаріїв та обмеження контрольної точки наведено в пояснювальній записці.
